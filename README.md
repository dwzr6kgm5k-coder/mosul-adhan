# أذان الموصل

تطبيق أندرويد بسيط يحسب مواقيت الصلاة للموصل يومياً ويشغّل الأذان بوقته حتى والشاشة مطفية أو بعد إعادة تشغيل التلفون.

## وين أعدّل شنو

| تريد تغيّر | الملف |
|---|---|
| المدينة، زوايا الفجر والعشاء، العصر شافعي/حنفي | `app/src/main/java/com/mosul/adhan/PrayerTimes.java` (الثوابت بأول الملف) |
| الألوان والخطوط وصيغة الوقت والتاريخ | `Ui.java` |
| الشاشة الرئيسية | `MainActivity.java` |
| شاشة الإعدادات (الدقائق والأصوات) | `SettingsActivity.java` |
| جدولة المنبه | `AlarmScheduler.java` |
| تشغيل الصوت والإشعار | `AdhanService.java` |
| اسم التطبيق | `app/src/main/res/values/strings.xml` |
| الأيقونة | `tools/make_icon.py` ثم شغّله |

## طريقة الحساب
- الفجر 18°، العشاء 17° (رابطة العالم الإسلامي)، العصر شافعي.
- الشروق والغروب مصححة لارتفاع الموصل (223 م)، وهذا يطابق شروق 6:53 المنشور بصفحة "مواقيت الصلاة لمدينة الموصل" يوم 26 تشرين الثاني 2026.
- أي فرق ثابت يتعدل من الإعدادات بـ + و − لكل صلاة.

## البناء
- **الأسهل:** افتح المجلد بـ Android Studio، وانتظر Gradle، ثم Build > Build APK(s).
- **بدون Android Studio:** `tools/build_apk.sh` (التفاصيل داخل الملف).

مفتاح التوقيع `keystore/adhan.jks` مو مرفوع هنا حتى محد يگدر يوقّع نسخة مزيفة. هو محفوظ عند صاحب التطبيق، وكلمة السر تنحط بمتغير `ADHAN_KS_PASS` وقت البناء. خلّه نفس المفتاح حتى أي نسخة جديدة تنصب فوك القديمة.
